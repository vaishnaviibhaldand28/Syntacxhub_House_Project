🏠 Syntacxhub House Project

📝 Description
This project is a Machine Learning-based Housing Price Predictor developed using the California Housing dataset. It utilizes Linear Regression to analyze how socioeconomic factors—specifically Median Income, House Age, and Average Rooms—influence property values. The model provides a automated way to estimate house prices with statistical validation.

🛠 Tech Stack
Language: Python 3.13

Libraries: * Scikit-Learn: For the Linear Regression model and data preprocessing.

Pandas & NumPy: For dataset handling and numerical computations.

Matplotlib: For generating performance visualization plots.

🚀 How to Run

1.Clone the repository:

Bash
git clone https://github.com/your-username/Syntacxhub-House-Project.git

2.Install Required Packages:

Bash
pip install pandas numpy scikit-learn matplotlib

3.Run the Analysis:

Bash
python "main.house project.py"
